README · Principle

The LLM is your second reader

This page is a demo. Scroll down, then click Copy for LLM or Download MD at the bottom. You'll get a clean Markdown version of everything inside <main> — without the nav, without the script tags, without the snippet itself.

Why ship this

People don't only read web pages anymore. They paste them into ChatGPT or Claude and ask follow-up questions. If your page is a wall of HTML with cookie banners and decorative widgets, that paste-in is messy and the conversation goes sideways.

So you ship the clean Markdown yourself. Three buttons, three kilobytes, ten minutes of work.

What's in the export

  • Title and date
  • Headings, paragraphs, lists, blockquotes
  • Code blocks, links, images, tables
  • A provenance footer pointing at the canonical URL

It skips <nav>, <script>, <style>, the snippet itself, and anything you tag with data-tiwy-skip.

A tiny example

Treat the LLM as a second reader, not a side effect.

<div class="tiwy" data-source="main"></div>

That's it. The snippet wires up the buttons, the serializer, and the clipboard fallback.
